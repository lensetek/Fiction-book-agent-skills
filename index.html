Physical Print & Digital Publishing Support

Manuscripts automatically formatted according to publisher standards

📘 Physical Print Book Formatting

Direct Microsoft Word (.docx) layout generator formatted for print publishers:

  • Print Presets: Novel 13x19 cm, A5 (14.8x21 cm), A4
  • Binding Gutter Margin (2.2 cm inside margin for book binding)
  • Mirrored Recto/Verso Odd/Even page headers & footers
  • Odd-page Chapter Openers with 100pt Space-Before titles
  • Dynamic Word XML Field Code Table of Contents

📱 Digital Web Reader (12 Chapters Demo)

Modern responsive mobile-first digital e-book interface:

  • Dark Mode, Sepia, and Light Theme toggles
  • Interactive Character Codex Pop-up when character names are clicked
  • Side-drawer Table of Contents & 12 complete chapter navigation
  • Structured EPUB export support for Amazon Kindle / Google Books

⚡ Fal.ai (Flux.1) & MCP Image Engine

High-speed, high-resolution AI image generation for comic panels, storybooks, & covers:

  • Fal.ai Flux.1 Schnell / Dev / SDXL integration via python helper
  • MCP (Model Context Protocol) server config (`mcp_config.json`)
  • Strict security: FAL_KEY loaded from environment variables
  • Native internal fallback to `generate_image` in Antigravity/Codex

⠎ Braille & Audio-Tactile Accessibility

Inclusive print & digital publishing features for blind & visually impaired readers:

  • Twin-Vision Dual-Format Interlined Unicode Braille (`⠁⠃⠉...`)
  • Audio-Tactile QR Code Bridges for chapter audio narration
  • Braille Embosser printer export (`generate_braille_text.py`)
  • EPUB3 ARIA Landmarks for screen readers & refreshable braille displays
